# SpamGuard AI – Academic Capstone Project

SpamGuard AI is a Spring‑Boot based spam detection system that now includes:

- Explainable‑AI token attribution (XAI) UI
- Adversarial‑attack lab (homoglyph, zero‑width, leet‑speak, good‑word attacks)
- Academic‑level benchmark with 5‑fold stratified cross‑validation and ROC‑AUC curves
- Auto‑generated defense dossier (Markdown) for viva/defense
- Various usability and performance improvements
